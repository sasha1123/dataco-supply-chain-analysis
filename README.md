# DataCo Supply Chain Analysis 📊

Data cleaning and exploratory data analysis project developed using **Python and Pandas**.

The objective of this project is to transform a real-world supply chain dataset into a cleaner and more reliable dataset for further analysis.

## 📁 Dataset

The original dataset contains:

- **180,519 records**
- **53 variables**
- Supply chain, sales, shipping, customer and order information

## 🔍 Analysis Workflow

The project follows a structured data preparation process:

1. Dataset loading and initial exploration
2. Data structure and data type analysis
3. Missing value detection
4. Duplicate record detection
5. Descriptive statistical analysis
6. Data cleaning and validation

## 🧹 Data Cleaning

During the cleaning process:

- Missing values were identified and quantified
- **0 duplicate records** were detected
- Columns with excessive missing data were removed
- The original dataset was preserved before transformations
- Remaining missing values were identified for further treatment

The dataset was reduced from **53 to 51 columns** after removing variables with insufficient information.
